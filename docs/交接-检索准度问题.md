## 2. 五类毛病（按机理分，不按题分）

### 类 1 · 长片在库里不存在 → 闸门整个不开

- **症状**：路标里混进一堆不相干的书；期望的书其实在，还排第一。
- **实例**：Q7「毛泽东怎么讲中国社会各阶级的分析」→ 多出文革史、黄金海回忆录。Q10「阿德勒心理学里，自卑感、人际关系和勇气是怎么串起来的」→ 多出《心理学与生活》。
- **机理**：`retrieve.py:304` 的判定是「问句最长档原片有没有人拿得出」。Q7 的最长档是「讲中国社会各阶级」（全库 DF=0）、Q10 是「阿德勒心理学里」（DF=0）→ 判定为假 → `:305` 整段跳过 → 只剩下面几行的 bm25 分差闸（`LIT_GAP=20`，`:35`）。两本闲书的余量只有 0.177 / 0.339，闸形同虚设。
- **注意**：这不是「书里有没有这个词」的问题，是**闸根本没问出这句话**。
- **别走的路（已实测排除）**：
  - 拧 `LIT_GAP`：要刷掉 Q7 闲书需 GAP<0.177，而 Q2 期望的《心理学与生活》余量是 10.086 → **Q2 一起死**。不存在一个常数同时修好 Q7 又保住 Q2。
  - 「档换成库里存在的最长档」：Q7 退到「毛泽东」、Q10 退到「自卑感」，两本闲书照样有 → 等于没改。

### 类 2 · 闲书真写了那个词，且走了「两路都中」

- **症状**：多出来的书证据是真的（正文里确实有那个词），而且它还是**该题分数最高、命中块最多**的一本。
- **实例**：Q4「梦是怎么被解释的，弗洛伊德怎么看」→ 多出《被讨厌的勇气》。它在这题里 best bm25 = −14.566、命中 10/14 块（占全书 71%），比两本期望书都强。
- **机理**：`retrieve.py:426` 只把**仅字面**交给 `_drop_weak_literal`；而该函数内部 `:296` 起全程只筛 `keep`（`:306` 只把 `both + keep` 拿去算头名分数，不筛 `both`）——**`both`（两路都中）不参与任何闸门**。而 Spec 明写「两路都中不动」。
- **致命点**：把 `both` 也过一遍最长片闸**没用**（它 `_has_longest('弗洛伊德')=True`）；换成分数/块数/覆盖率闸**会先砍掉期望的《自卑与超越》**。
- **结论**：这一类**不是调闸能修的**，需要新能力（见 §3 候选 3）。它必须同时解释清楚 Q2（同一本教材、同结构、**必须留**）和 Q13（生活题靠地图进栏、不能被误伤）。

### 类 3 · 问句黏字 / 口水词 → 证据被带跑

- **症状 A（零命中）**：「斯坦福监狱实验说明了什么」→ 返回空。可「斯坦福监狱实验」在《心理学与生活》里有 **4 块**。`parse_query` 把「实验说明」粘成一个串（DF=0），`_match_gate` 就抓瞎。同形：「埃里克森讲的人的一生要经过哪几个发展阶段」（`埃里克森` DF=4）。
- **症状 B（口水词单独过闸）**：「批林整风运动是怎么一回事」→ 5 本书一起进。`批林整风运动` DF=0 → 闸门退化成让「一回事」（DF 80 块）单独过闸。
- **症状 C（空壳）**：Q14「《被讨厌的勇气》大概讲什么」→ 只回 8 个字。书名被拆成「讨厌」「勇气」，唯一的长片是「大概讲」（DF=1，而唯一有它的文档是**另一本书的地图**）→ 字面 0 本；唯一被召回的地图又被书名号过滤删掉。
- **机理**：`parse_query`（`index.py:39`，功能字表在 `:16` 的 `FUN_CHARS`）把内容词和套话粘成 DF=0 的长串；`_match_gate`（`index.py:397`，长片挑选在 `:412-417`）只把 DF>0 的长片拼进闸，一片都没有时行为退化。
- **纪律提醒**：修它**不许**写成「如果问句含『讲了什么』就走 X 路」——那就是按问句类型做代码路由，仓库明令禁止。要改的是**「什么算有效证据」这条通则**。

### 类 4 · 死书占位

- **症状**：一本**没有可用正文**的扫描书被顶到「两路都中」第一栏，把真答案挤到第二栏。用户点开会看到 450 行图片链接。
- **实例**：`book-f83968a1`（徐景贤《十年一梦》）——整块 9947 字里 450 行是 `![](index-N_M.jpg)`，**中文正文只剩 22 字**。问「徐景贤在文革中都干了些什么」，它排第一，真答案《十年非梦》排第二。
- **机理**：它的**书名/地图**是好的、正文是空的 → 靠书名和地图判成两路都中。
- **性质**：这是「入库体检查不严」的延伸，但也伤检索准度（占了名额、还把答案压下去）。

### 类 5 · 导航件的块名能被匹配

- **症状**：《自卑与超越》的「索引」块被当命中，还被列为建议块；点开是空的（正文不进索引）。
- **机理**：`索引`/`参考文献`/`术语表`/`目录` 的**正文**按设计不进索引（`index.py:84` 的 `is_nav_name`，`:316` 把正文置空），但**块名照样写进 `name` 字段并分词**（`index.py:326`），所以块名能被匹配上。
- **性质**：小而明确的一个洞。

## 3. 四条候选修法（**都做过只读实跑验证，一个都没落地**）

| # | 修法 | 改哪 | 实测效果 | 风险 / 未解 |
|---|---|---|---|---|
| 1 | **退让到库里真有的子串**：某段长片整串全库 DF=0 时，退到它内部最长的、全库存在的连续子串（长度仍须 ≥3；找不到就按现行为） | `parse_query`（`index.py`） | 全组跑过：只动 Q7、Q10 —— Q7 从「毛选+2 闲书」变成**只剩毛选**；Q10 变成**只剩两本期望书**。其余 11 道 Q + W1–W16 **一字未变**，热耗时 +1~2ms | 退让可能落到很常见的子串（如「心理学」DF 61），那时闸等于没开（不会更坏，但也修不了）→ **必须用合成闸钉住这一类** |
| 2 | **书名号整串当一个原片**（不替代原有片，只是多一个） | `parse_query`（`index.py`） | Q14 从 8 字空壳 → **正确给出导读+地图**；全组只有 5 道带《》的题受影响（Q9/Q12 字数微变、书单不变），W 组零影响 | 书名号里包的不是书名、且该串恰好在库里时，它会成为最长档从而收紧召回 → 需合成闸 |
| 3 | **主题指纹**：入库/建索引时从 `地图 + 书名 + 章名 + 导读` 编译一份 20–40 词的主题表，跟着索引活在内存里；排路标时看「命中的词是不是这本书的主题」 | 新能力（`index.py` + `retrieve.py`） | **还没量过**——这是接手的重点 | 不加依赖、不落盘；但必须证明它能救 Q4 且**不伤 Q2/Q5/Q13** |
| 4 | **导航件块名不进字面** | `index.py`（插入时的 `name` 字段） | 未量 | 会不会影响「目录」类正常块的可搜性，要先量 |

## 5. 红线（照抄自 `AGENTS.md`，不是建议）

- **不许为某一道题、某一本书、某一个问句写规则或过滤器。** 禁加书名黑名单、禁停用词、禁对真库拧 `LIT_GAP`。
- **不许按问句类型做代码路由。** 不许写「含『大概讲什么』走 X」「含书名号走 Y」。改的必须是「什么算有效证据」这种对**任意问句**同一套的通则。
- **不许**改冻结题集的期望就题；不许用临时题替换 Q1–Q14。
- 不许把向量库当正本、不许索引落盘、不许新加依赖（标准库优先）。
- 改 `mcp/` 之前**必须有 `docs/本轮Spec.md`**；Spike（只读探路）先于 Spec。
- **本仓库有"记账写错先例"**：曾把「准 9/13」误报成 10/13，也曾在验收记录里写成「地图理由只报 len≥3」而实现是 len≥2。**动手前先自己跑一遍，别信本文档的数字**——本文档的值只保证在 §1 那个 HEAD/哈希上成立。
