# 主控结论：语义检索对本库怎么加

> 回收三路 Spike：`调研-开源知识库项目.md`、`调研-语义检索.md`、`调研-Obsidian双链.md`。
> 对照本库失败类与 `需求.md`。不改 `mcp/`。等人点头后再写 `docs/本轮Spec.md`。

## 结论（先说）

**不要换引擎（C）。不要先上向量。**

现成架子（FTS 字面 + 地图两路 + 路标无正文）和开源里「给 Agent 的资料室」是同一条路：Karpathy LLM-Wiki 编译、[LLM-Wiki 论文](https://arxiv.org/abs/2605.25480)（机构署名「腾讯」**待考**，论文本身真实）量化了「结构优先于正文、只回页身份」；[tobi/qmd](https://github.com/tobi/qmd) 是工程对标（FTS5 + 向量 + RRF，query 回身份、get 才取正文）。

**FTS5 一手纠错：** 官方 `bm25()` **每列一个权重**，书名/章名/正文分列就能做字段加权，不是「FTS5 做不到」。`NEAR` 可做片间邻近。默认 `unicode61` 把整段中文当一个 token，所以二字片必须预切——这是引擎硬约束。写 Spec 前还要实读 fts5.html 的 vocab/DF 节，不许拿未读章节编数字。论文消融表里的 0.739/6.1 F1 等格点，摘要只背书「+2.0–8.1 F1」区间，进 Spec 前须核 HTML 正文。

本库卡的不是「没有语义引擎」，是**语义信号太薄**：地图约 5 条提纲、没有别名、章名/正文没有分权、二字专名进不了「长证据片」、aboutness 不认「第 X 节」。

**推荐：A（加厚地图 + 别名 + 字段权重 + 扩词闸）先做。B 的零依赖子集（RRF/MMR/原查询加权）可同轮。向量只在 A 之后仍有「零字片同义」才上，且只做召回、仍只回身份。**

语义检索那份正文选「查询侧别名扩写」，附录选「文档侧书指纹进地图」。这不是打架：一层修「说法对不上」（A），一层修「词在闲书里」（B）。**同一轮地图 schema 可以两样都写上**，不必先上向量。附录里拿 Q4/Q7/Q10 当硬失分，那是第 6 轮口径；第 7 轮后 Q 组已 13/13，真还红的是 N 组。venv 已有 onnxruntime、无 torch；655 块暴力扫向量也划不来，且与索引不落盘冲突。上向量前必须先交出附录写的三个数（重建耗时、只向量能救的题数、误召回增量）。

## 三路证据怎么合

| 来源 | 可采 | 主控修正 |
|---|---|---|
| 开源项目 | qmd 的 RRF/原查询×2/字段权重；LLM-Wiki 的 aliases 优先；MMR 去冗余；「两本都相关就都列」 | C 换 qmd 要索引落盘，和「进程内索引」冲突，不作首选 |
| 语义检索 | 同义 / aboutness / 意图必须分开；embedding 会让 Rust/埃里克森更混；重排前必须先放大候选池；HyDE 扩写会喷出「变化」「发生」 | N8 **不是召回=0**：文革史进了，排第 3，闸开在「变化」。别名要变成**最长证据片**，不能只当 OR 公共词 |
| Obsidian | 偷 aliases、MOC 加厚（须覆盖**全层**章名，含「第 X 节」）、标题加权；图谱/块引用 `#^id` 不要 | 未链接提及可当「跨书≥2 次」的候选信号，**不当边、不占格**；别名只写地图 |

第 7 轮 aboutness 误杀「武斗」：章名是「第二节 武斗」，闸只剥「第 X 章」，二字片不算长证据；黄金海地图写着「是怎么发生的」。这是**结构闸 bug + 地图太稀**，不是缺向量。

Obsidian 路事后复现（已改完两处计数错误）：**7 张地图里一个「武斗」都没有**；`aliases` 字段全库地图为零。毛选另有「不用武斗」篇、文革史有独立块 `第二节 武斗`、黄金海里有多条「武斗」小标题。地图没覆盖章，第二路等于没开。图谱节点大小官方是**入度**，不是 PageRank；本库书正文也没有双链边，图谱 ranking 无材料。SiYuan 的 `name`/`alias` 细则只见第三方转写，**不采信进 Spec**；能采的是「身份与正文分离」这个形状。

## 对本库失败类：什么能修

| 类 | 例 | A（地图/别名/字段） | 向量 | 改打分口径 |
|---|---|---|---|---|
| 说法对不上 | 林彪事件 vs 批林整风 | **主修**：地图 aliases + 查询侧只扩专名 | 后手 | 否 |
| 二字专名 / 闸误杀 | 武斗被 aboutness 杀 | **主修**：章名（含节）进 aboutness；字段权重 | 无用 | 否 |
| 同名异义 | 埃里克森、Rust, J. | 拉丁词必须与中文主题共现；参考文献/脚注降权 | **会更糟** | 否 |
| 闲书真有该词 | 文革史「原始积累」 | 字段权重 + 结构 aboutness | 无用 | 部分：两本都在写可都留 |
| 两本同史实 | 一月风暴、破四旧 | MMR 去冗余，5 格别被一本占满 | 无用 | **准二值过严**，属体验 |
| 建议块 3 格 | 实践论被挤 | 配额/排序，不是检索 | 无用 | 否 |

「语义」在工程上 = **hybrid 四段**（字面召回 → 稠密/稀疏 → RRF → 交叉编码器）。对本库：① 已有；② 暂不必；③ 有第二路名单才需要；④ 候选池被焊死在 5，重排无东西可排。见 [BGE-M3](https://huggingface.co/BAAI/bge-m3)、[RRF 2009](https://dl.acm.org/doi/10.1145/1571941.1572114)、[HyDE](https://arxiv.org/abs/2212.10496)。

## A / B / C

### A · 只加一层（推荐先做，零新依赖）

1. **地图加厚（MOC）**：入库/lint 要求「能解决什么」覆盖主要非导航章名，而不是固定 5 条。
2. **aliases 段**（只在地图）：事件/人物别称 → 章身份。检索优先打别名与章名。
3. **字段权重**：书名/章名/地图 > 正文。修「发生」「变化」撑满。
4. **aboutness 认「节」**、二字专名可当结构命中（出现在章名里）。
5. **建议块**：问句里点名的篇名优先占格（实践论）。
6. **查询侧扩词**：只扩地图里的别名/专名，**禁止**扩「变化/发生/怎么回事」。扩词走现成弱命中闸，不出现在命中理由。

侵入：`ingest` 地图生成、`retrieve` aboutness/建议块、地图 schema。不改书、不回正文、不上模型。

### B · 改检索层，六扇门和路标无正文都留

- **现在就能做、仍零依赖：** RRF（若地图路和字面路要融成分数而不是分栏——本库已是三栏，RRF 不是刚需）；MMR 让 5 格来源多样；原查询加权。
- **以后才做：** 向量/BGE-M3 **只召回身份**。前提：A 之后仍有「问句与书零二字片重叠」的题。代价：新依赖；索引不落盘则每次进程全量嵌入（无公开成本数据，要自测）。Embedding **不能**当同名异义的解。

对标：[qmd](https://github.com/tobi/qmd)（不要整包换）。

### C · 换引擎

**不做。** FTS5 337 万字建索引约 2.5s、查询约 4ms。瓶颈在证据定义和地图表面积。换 qmd 等于接受索引落盘 + 向量维护，六扇门还得重焊。

## 体验「究极可用」还要改的口径（规格，不是算法）

开源没有一家在「两本都相关」时强行只留一本。本库「准 = 多一本非期望书就整题 0」会把「黄金海和文革史都写一月风暴」打成失败。

建议（需人点头才改 `docs/验收标准.md`）：

- 准：闲书 = **与问句主题无关**；同主题第二本不算闲书。或改成「期望必须在、闲书不占 Top-1」。
- 路标体验：5 格用 MMR 保证来源多样，而不是 5 本都沾「变化」。

这不是检索思路错，是打分在惩罚「库里真有两本史书」。

---

## 明确不要做

- 搜索带摘录、自动灌命中章（死规矩 2、6）。
- 把「变化/发生/分析」当停用词。
- 为单题/单书过滤器。
- 未链接提及当 aboutness。
- 往书正文插双链/`^blockid`。
- 检索路径里塞 LLM（Agent 侧扩写可以，工具内扩写用**地图别名词表**，不要每次调模型）。
