## 3. 切块规格

**不变量：每块 ≤ 4000 字，且块名来自书里的标题。**

为什么是 4000：压在大多数书的自然单元中位之上（毛选 1687、心理学与生活 1186），只切超大块、不撕碎正常的节；且 5 × 4K = 20K ≤ 24K 整次总顶，一次能读满 5 块（若块是 8K，5 × 8K = 40K 超顶，「最多 5 块」等于作废）。

四级降级，按顺序试：

1. **标题树下沉**——从一级标题起：节点 ≤4000 → 自成一块；超 4000 且下面还有子标题 → 下沉；没有子标题可下 → 进第 2 步
2. **段落贪心打包**——按空行切段，逐段累加到不超过 4000 就收一块。**不是死板地每 4K 一刀**，永远落在段落边界上
3. **句子上断**——只有单个段落自己就超 4000，才在 `。！？；」』` 上断；还超就硬断
4. **中文结构行兜底**——整行 ≤40 字、以「第X章/第X节/第X篇/一、/（一）/壹、」开头、行尾没有 `。！？` → 当结构用（**只用于切分和命名，正文不改一字**）

**命名优先级**：自己的标题 → 最近上级标题 +（i/n） → 该块第一句前 20 字

不合并同级小块（保名字干净，宁可块小）。

**硬要求：字数守恒 ≥99%**——切块算法再花哨，也不许把书里的字弄丢。

## 4. 索引规格

- **SQLite FTS5，内存模式**（`sqlite3 :memory:`）——Python 标准库自带，**零新依赖**
- 进程内建：首次检索时建一次并缓存；**进程退出即消失，不落盘**
- 列与权重：标识(0) / 块名(3.0) / 正文(1.0)
- 分词：连续汉字的**二字片** + ASCII 词；**单字词也要能命中**（这是旧实现的硬缺陷，W17–W20 专门盯它）
- **虚词降噪**：高频虚词片不参与召回——旧实现拿「的人」「关系」「分析」撞出了一堆无关书（Q2/Q3/Q7 的病根之一）
- **导航块降权**：链接行占比高的块（原书目录页）只按块名进索引，正文不进（内容照旧可读、不删）
- 排序：bm25

---

## 5. 检索规格（`kb_search`）

- 输出**路标**：最多 5 条；一条一本书；每条最多 3 个建议块
- **只回身份和命中理由，永不回正文**
- 每条路标带：
  - **像在**：命中哪个字段 + 命中什么词
  - **命中分布**：这一问在这本书里命中多少块、分布在哪几卷/篇 ←「要不要继续」的依据
  - **已读标记**：`[已读]`（数据来自 `检修/calls.jsonl`，窗口与写笔记求证一致：最近 100 条 / 24 小时）
- **撞不上就返回空**，宁可空也不推无关的书
- 索引不可用 → 退化成只扫抬头，并在路标里**明说**

---

## 6. 阅读规格（`kb_read`）

- **不变**：点名制、最多 5 块、整次 24000 字顶、每块 8000 字顶（兜底，入库已保证 ≤4000）
- **新增**：每次阅读末尾附一行**邻块索引**（只有块名，无正文）
- **不引**翻页游标、不引会话内隐藏状态——续读靠 Agent 照邻块名字再点名
