> 验收：`docs/验收标准.md`

## 1. 本轮要修好的 8 件事

1. 书里有的词却搜不到  
2. 搜到了也读不完（超长块截开头、再读还是开头）  
3. 不能认死按卷/按章切，中文书、没目录的书也要能切  
4. 不许自信地给错书；库里没有的必须空  
5. 单字实词也能搜到  
6. 找到一段后，Agent 能判断还找不找（给事实，不喊停）  
7. 充分但不多余：路标无正文，一次不灌全书  
8. 切完不丢字、块名来自书里  

**入库必须配合检索**：块的身份要落在「篇/章」上，正文进索引；抽词回捞（W1–W16）是入库的验收，不是检索的附加题。

**本轮明确不做：** 向量 / RAG、jieba、第七个 MCP 工具、索引落盘、大模型生成抬头、改书正文、隐藏翻页游标。

## 3. 切块：自然篇为文件，不预切 4K

**不变量：磁盘上一块 = 书里的一个自然篇/章；块名来自书里，不许编。**

存储粒度和阅读窗口分开：

| 层 | 粒度 |
|---|---|
| 磁盘文件 | 自然标题单元（毛选认到 `###` 篇，心理学/勇气认到有用的 h2/h3，扁平书保持章） |
| 索引 | 按块正文建帖（目录/索引/参考文献/术语表正文不进） |
| 阅读 | 单窗 ≤ 8000 字；超长篇用显式身份 `书/<slug>/<块名>#2` |

**为什么不预切 4K 文件：** 4K 是阅读口，不是文件大小。`《中国社会各阶级的分析》` 约 6920 字，8K 窗一次读完；4K 会撕成两块，和 Q7「最少 1 块」打架。《实践论》里「两次飞跃」落在开头 8K 内；4K 会把答案踢进第 2 块。5×4K=20K≤24K 是假理由——总顶 24000 自己会卡住一次读量。

### 3.1 切点顺序

1. **剥标题残渣**（只用于命名和切点，正文不改）：去掉 `[\\*](#id…)`、结尾的 markdown 链接、行内 HTML 锚点。`实践论[\\*](#id0a)` → `实践论`。  
2. **标题树下沉**：认 ATX 的 `#` 到 `######`，按深度切。毛选：h1=卷不要当块，**块落在 `###` 篇**。卷名/时期行并进其后第一篇，不要空的「第一次国内革命战争时期」文件。  
3. **中文结构行**（仅当**该转换产物里一个 ATX 标题都没有**时启用）：整行 ≤40 字、以「第X章/第X节/第X篇/一、/（一）/壹、」开头、行尾没有 `。！？：；`。毛选有 160 条篇内「一、」，默认启用会撕篇——**有 `#` 就禁用。**  
4. **仍超长且没有子标题**：不预切文件。阅读侧按 8000 开窗。  
5. **命名**：自己的标题 → 最近上级标题 → 该块第一句前 20 字。禁止 `chapter` / 空名。同名加序号。不合并同级小块。

**字数守恒 ≥99%**：切块后各块**正文**（去 YAML 头）字数之和 ≥ 切块前 markitdown Markdown 的 99%。对照物是转换产物，不是 epub。第一个标题之前的字不得丢掉（现行代码会丢，本轮要修）。

**导读：** 只留顶层目录（卷/章这一级），不要列 394 篇。细块靠文件名和索引。

**附录类文件可整块留盘**（参考文献、索引、术语表、原书目录页），但检索时正文不进索引。

## 4. 索引：进程内 FTS5，语片查询

- SQLite FTS5，`:memory:`，零新依赖。stdio 长活进程，首次需要时从正本建一次并缓存；**入库成功后使缓存失效**。进程退出即消失。  
- 「查询时不读正本」只在索引已热之后成立；冷启动那一次必须读正本。  
- **不要**把生中文丢给 unicode61 / trigram（整段汉字会变成 1 个 token，2 字词 MATCH 为空）。先在 Python 里切成空格分隔的片子再插入。  
- **索引侧：** 连续汉字的二字片 + 单字 + ASCII 词。  
- **查询侧（语片，不是整句 OR 袋）：**  
  1. 丢掉功能词：什么/怎么/如何/这个/一个/我们/自己/的/了/是/和/与/及/或/在/有/被/把/让/就/都/也/还/很/到/从/对/为。  
  2. **不要**把「关系」「分析」「合作」放进停用表。  
  3. 剩下的连续汉字 / ASCII 当语片。片长 ≥2：片内二字片 **AND**（短语）；片长 =1：查单字帖。语片之间 OR。  
  4. 问句里 DF 最低的实词语片全库为 0 → 整句空（Q6：PyTorch）。  
- 列权重：标识 0 / 块名 3.0 / 正文 1.0；bm25。  
- **导航块正文不进索引**：文件名含「目录」「目 录」「索引」「参考文献」「术语表」；内容照旧可读。不要用「链接行占比」当探测器（导读、译者简介、第四卷都会误伤）。导读本身走标题列，不当目录页剥正文。  
- 索引构建失败 → 退化成只扫抬头，并在路标里**明说**。  
- **零命中不回退抬头**（回退会把「关系」又撞回无关书）。

## 5. 检索规格（`kb_search`）

- 最多 5 条路标；一条一本书（或一条笔记）；每条最多 3 个建议块。  
- **只回身份和命中理由，永不回正文。**  
- 每条带：  
  - **像在**：命中哪个字段 + 命中什么语片  
  - **命中分布**：这一问在这本书里命中多少块（只报数字，**不铺卷篇清单**）  
  - **已读标记**：可选。若做，只用**本 MCP 进程内存**里本次读过的身份；**禁止**复用 `检修/calls.jsonl` 最近 100 条 / 24 小时（会串会话）。本轮砍掉已读也可以，不挡工具闸门。  
- 撞不上就返回空。宁可空也不推无关的书。  
- 建议块身份必须是可 `kb_read` 的：`书/<slug>/<块名>`，超长篇可直接给 `书/<slug>/<块名>#1`。

---

## 6. 阅读规格（`kb_read`）

- 点名制不变。单次最多 5 个身份、整次 24000、**单窗 8000**（这是窗口顶，不是「入库已保证文件 ≤4000」）。  
- 超长篇：同一文件按 8000 切开窗，身份为 `块名` 或 `块名#n`（n 从 1）。`#1` 与不带 `#` 等价。同一窗再读仍是该窗；要点下一窗就点 `#2`。  
- 这不是隐藏游标：窗口号码写在工具参数和返回的邻块行里。  
- 每次阅读末尾附一行**邻块**（只有名字）：上一篇 / 下一篇，以及同篇上一窗 / 下一窗（若有）。  
- 超总顶截断并标明没读到的项。某一身份找不到：这一项失败交还，其它照给。没身份或点名整本：整单拒绝。  
- 笔记超 8000 同样开窗，规则相同。

1. 规格与文档（本文 + `需求.md` + 验收 + 功能流程 + 计划 + AGENTS）——先 commit

6. 线上机械跑整句 Q 的召回/无关书 + W1–W16；Q9–Q12 的轮次/块数只记为 Agent 剧本，不当代码完成线。
