## 1. 本轮要解决什么

资料室能进不能出。坏书、不想要的书，Agent 没有正门可走。入库体检只查缺地图，无文字层、切点丢掉层级、空心 slug 的书照样进检索。

**对类，不对题。**

- 退的是「一整本已经入库的书」这一类对象，不是徐景贤、不是资本论。
- 拒的是「转换产物几乎没有可检索汉字」这一类源文件，不是某一本扫描 EPUB。
- 标的是「一块长到不像章」「目录名剥完只剩数字」「同名章平铺」这一类切块后果，不是 `1-3-3` 这个字符串。

**本轮不做：** 向量；新依赖；索引落盘；OCR；改书正文；按章删；删归档源文件；新开第七扇门；认册/卷再切；字形映射表；检索闸门；为刷准加书名黑名单。

## 2. 产品判断（必须先写进 `需求.md`）

「书不改」= **不重写、不按章删、不按章改**。  
「书不改」≠ 整本不能退出资料室。

退书是入库的反操作，挂在**净化**这扇门上（卡帕西 lint = 体检 + 清理），**不**新开第七扇门。函数名仍叫 `kb_lint_notes`（兼容已接好的 Agent），说明书和工具描述改成：笔记、地图、**整本退书**。

源文件层（`原始资料/`、`原始资料归档/`）本轮仍不动。退的是 `资料/书/<slug>/`。归档还在，以后可以再指定入库。这是「raw 不可变」那一层，不是回收站产品。

## 4. 退书协议（焊死）

仍是一门两步：`action=scan` 只列不删；`action=apply` 交 JSON 才动手。

### 4.1 身份

- 退书唯一合法 target：`书/<slug>`（两段，slug 非空）。允许别名 `资料/书/<slug>`，代码归一成 `书/<slug>`。
- **非法**（整单拒绝，库不变）：`书/<slug>/章`、`书/<slug>/导读`、`书/<slug>/地图`、`书/<slug>/正文`、磁盘路径、`笔记/<slug>` 配 `op=withdraw`、空 slug、`书/`、`书/<slug>/extra/more`。
- 旧护书闸仍在：`op=delete|update|merge` 碰到书正文或 `书/<slug>`（非地图）→ 整单拒绝。地图仍只走 `update`/`stale`。

`op` 用 **`withdraw`**，不用 `delete`。笔记那条 `delete` 复制过来不能误伤书。

### 4.2 apply 行为

清单仍是 JSON 数组。可以一本清单里同时：

- 笔记 `delete` / `update` / `merge`
- 地图 `update` / `stale`
- 书 `withdraw`

任一项非法 → **整单拒绝，已做的也不该发生**（先校验再动手，与现 lint 一致）。

`withdraw`：

1. `资料/书/<slug>/` 必须是已存在的书目录（有 `导读.md` 或至少是目录）。不存在 → 整单拒绝，说明身份。
2. `shutil.rmtree` 该书目录。
3. **不**删 `原始资料/`、**不**删 `原始资料归档/`。导读里的 `source` 只写进回报，让 Agent 知道还能再入。
4. `invalidate()`。
5. 回报人话：`已退 书/<slug> 《title》；源文件仍在 <source 或「导读未写 source」>。要再入走指定入库。`

一次清单可退多本。每本一行。

### 4.3 scan 加什么（只列不删）

现有笔记/地图条目保留。对 `资料/书/<slug>/` 每本追加机械项（有则写，没有不写）：

| 代码理由（人话，写进清单） | 判定（对类） |
|---|---|
| 缺地图 | 已有 `map_problems` |
| 无文字层 | 该书所有块（不含导读/地图）合计：图片行（`![...](...)`）≥ 20 且汉字（`\u4e00-\u9fff`）< 图片行 × 8；**或** 汉字 < 200 **且** 图片行 ≥ 5。纯短文、没有图，不算无文字层 |
| 超长块 | 任一非导读/地图块字符数 > `8 * 8000`（= 64000，八个阅读窗） |
| 同名章撞车 | 去掉末尾 `-数字` 后缀后，同一短名出现 ≥ 3 块（三个「第一篇」平铺这一类） |
| 空心目录名 | slug 匹配 `^[0-9]+(?:-[0-9]+)*$`（剥完只剩数字和横线） |
| 文件名乱码 | 任一块文件名含 U+FFFD，**或** 文件名里的汉字有 ≥ 2 个落在 BMP 基本汉字区（U+4E00–U+9FFF）之外 |

清单末尾照旧：动手请 `action=apply` 交 JSON。补一句：退整本用 `{"op":"withdraw","target":"书/<slug>"}`；不能退某一章。

scan **不**替 Agent 决定退谁。有用但切烂的书（资本论这一类）会亮超长块/同名章/空心目录名，退不退是 Agent 的判断。

### 4.4 索引

- `withdraw` 之后必须 `invalidate()`。
- 笔记 `delete` / `update` / `merge` 之后也必须 `invalidate()`（现缺，一并补上）。
- 地图 `update`/`stale` 现已 invalidate，保持。

## 5. 入库体检（只拦新进的）

现有书不自动重切、不自动退。新进的源文件多两道闸。

### 5.1 无文字层 → 这本失败，不算入完

在 `convert_one` 里：markitdown 已经产出全文、**尚未** `mkdir` 书目录、**尚未** 搬源文件。

对转换全文做与 §4.3「无文字层」同一套计数（图片行够多且汉字极少；不要把没图的短文误判进去）。命中则：

- 抛/返回失败（走现成 `ingest_sources` 的失败交还）。
- 书目录不出现。
- 源文件**留在原处**（收件箱或指定路径），不进归档。
- 失败人话：`转换产物几乎没有可检索的正文（无文字层）。本工具不 OCR。换文字版再入，或不要这本。`

其它文件继续。这是类闸门，不写书名。

### 5.2 空心 slug → `book-{hash8}`

`slug_base` / `unique_slug` 之前：`slugify` 结果若为空、或匹配 `^[0-9]+(?:-[0-9]+)*$`，改用 `book-` + 原始文件名 stem 的 sha1 前 8 位（已有 `book-{hash}` 退路，只是今天数字编号抢先了）。

导读 title 仍按现有 `pick_title`，不把 hash 当书名。

**不**重命名库里已经叫 `1-3-3` / `1-7` 的目录。要改名 = 退书 + 再入（下一轮或人手点）。

### 5.3 超长块 / 同名章 / 乱码文件名

新入仍落盘（字本身可能是通的），但：

- 入库回报里写明「未入完：…」（比只报缺地图宽）。
- 缺地图逻辑保留。
- 这些书进检索（结构不决定可搜性）。Agent 用 scan 看见，要退走 `withdraw`。

不要在检索里把「未入完」静默丢掉——资本论这类题还要靠它答「原始积累」。退是人/Agent 的判断。

### 5.4 书名「第一章」

本轮**可以**做这一条小修，因为它已经写在需求里、只是没挡住：`pick_title` 在没有 `meta_title` 时，候选若匹配 `^第[0-9一二三四五六七八九十百千]+章` 则跳过，再试下一个；都像章名才退回原始文件名（`fallback`）。

这是「书名来源优先级」的执行，不是为文革史开特例。无 EPUB 元数据的文字 PDF 都会走到这一支。
