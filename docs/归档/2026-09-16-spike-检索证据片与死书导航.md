## 1. 要搞清什么

交接单五类是不是同一套「什么算有效证据」的病；候选 1/2/3/4 哪个对类有效、哪个会伤 Q2/Q13/W/负样本。

**本 Spike 范围：** 问句原片怎么当证据、无正文的书、导航件块名。  
**明确不进本轮：** 主题指纹（见 §4）；入库切块/OCR；拧 `LIT_GAP`；书名黑名单；按问句类型路由。

`parse_query` 是纯字符串函数，拿不到 `_df`。DF 退让不能写进 `parse_query` 本体，要另开一层「证据片」（先 `parse_query`，再两边剥，再给 MATCH / `_match_gate` / 最长片闸共用）。《》加片不依赖 DF，可以留在 `parse_query`。现有 `_quoted_ok` 书名号收窄保留，不加新的问句类型路由。

收紧 `both` 去走「正文拿得出最长片」会打掉 Q13（期望书最长片只在地图里）。both 仍不走 `_drop_weak_literal`。只补第 6 轮已写未做的：地图侧没有长原片就不要抬成 both。

## 2. 五类机理（当前代码，已复跑）

### 类 1 · 最长原片整串 DF=0 → 闸没开

`retrieve.py:304`：最长档谁都拿不出就整段跳过，只剩 `LIT_GAP=20`。Q7 闲书余量 0.177，闸形同虚设。

`parse_query` 把套话粘在专名边上：Q7 `讲中国社会各阶级` DF=0；Q10 `阿德勒心理学里` DF=0。

### 类 2 · 闲书正文真有该词，且被抬成「两路都中」

Q4：三本都有「弗洛伊德」在**正文**，谁的主题表（地图+书名+章名+导读前 2000 字）里都**没有**「弗洛伊德」。被讨厌的勇气 best bm25 最高、命中 10/14 块。

`retrieve.py:395-399`：`bid in lit_set or _map_has_piece` —— 字面命中就能把弱地图抬成 both（第 6 轮 Spec 写的是「只靠 len<3 不当地图命中，有字面则降成仅字面」，实现没降）。

### 类 3 · 黏字 / 口水词 / 书名被拆

| 题 | parse 原片 | 发生了什么 |
|---|---|---|
| N14 | `斯坦福监狱实验说` DF=0 | `_match_gate` 无 DF>0 长片 → 空 |
| N15 | `埃里克森讲` DF=0 + 超长黏串 DF=0 | 空 |
| N18 | `批林整风运动` DF=0，`一回事` DF=52 | 闸开在口水词上，5 本进 |
| Q14 | `讨厌`/`勇气`/`大概讲`(DF=1，在**另一本**地图) | 字面 0；唯一地图被《》过滤删掉 → 8 字空壳 |
| N5 | `十年非梦里`、`写红卫兵大串联` 全 DF=0 | 空 |

Q14 的 `大概讲` **不是 DF=0**（DF=1），所以「DF=0 才退让」修不了它，必须另加《》整串当原片。

### 类 4 · 死书占位

`book-f83968a1` 唯一一块 `正文.md`：汉字 22、图片链接 450、han/chars=0.011。其它 7 本 han/chars 0.49–0.84。书名/地图是好的，正文是空的 → 靠书名进两路都中，压在十年非梦前面。

闸：一块汉字 <80 **且** 图片链接 ≥10 → 无正文块；一本所有非导航内容块都无正文 → 死书。本库只打中这一本。

### 类 5 · 导航件块名能被匹配

`index.py:316` 导航件正文置空，`:326` **块名仍分词进 `name`**。N17 建议块第一是 `书/book-2cde2fad/索引`（磁盘上该文件有 4689 汉字，但按设计不进正文索引，点名读会看到「不必读」）。

## 3. 候选 1/2：怎么退让才对类、不伤负样本

### 3.1 任意内嵌子串（交接单原文）

`DF=0` 的长片 → 该片内部**任意位置**最长 DF>0 子串。

能修 Q7/Q10/Q14/N14/N18/N10。**但 N12 负样本翻车**：`量子纠缠能不能用来超光速通信` 整串 DF=0，内嵌命中「不能用来」→ 空变成毛选+资本论。N15 内嵌「几个发展阶段」→ 只回毛选，期望的心理学教材反而不在。

内嵌子串不是「黏在边上的套话」，是把一句不存在的话切出库里碰巧有的碎词。

### 3.2 只剥两边（本 Spike 采用）

`len≥5` 且整串 DF=0 时，只试去掉前缀/后缀各 1～2 字（保留 ≥3），取还在库里的最长者。找不到就保持 DF=0（现行为）。《》内整串**额外**当一个原片，不替代原片。

这是「黏字发生在切词边界」的通则，不点名「讲/说/里」。

| 题 | 退让 | 书面 |
|---|---|---|
| Q7 | 讲中国社会各阶级 → 中国社会各阶级 | 毛选+文革史+黄金海 → **毛选** |
| Q10 | 阿德勒心理学里 → 阿德勒心理学 | 三本 → **两本期望** |
| Q14 | +《被讨厌的勇气》 | 空 → **被讨厌的勇气** |
| N5 | 十年非梦里 → 十年非梦；写红卫兵大串联 → 红卫兵大串联 | 空 → 十年非梦+文革史（期望书在，仍有闲书） |
| N10 | 论持久战里 → 论持久战 | 5 本 → **毛选** |
| N14 | 斯坦福监狱实验说 → 斯坦福监狱实验 | 空 → **心理学与生活** |
| N15 | 埃里克森讲 → 埃里克森；超长串两边剥不动 | 空 → 心理学与生活+自卑与超越+资本论（期望在；资本论是同名异义） |
| N18 | 批林整风运动 → 批林整风 | 5 本 → **文革史** |
| N12 | 两边剥不到任何 DF>0 子串 | **仍空** |
| Q2/Q4/Q6/Q13 | 不触发 | **不变** |
| W1–W16 | 不触发 | **所在书全在** |

Q11 会剥掉「说认识…」的「说」，书面仍是毛选。Q9/Q12 只因《》多一个原片，书面不变。

## 4. 类 2：主题指纹不能用；结构 aboutness 能用

对 Q2/Q4/Q5/Q13/Q10/W1/W13 量了「问句 len≥3 原片 ∈ 地图+书名+章名+导读前 2000 字」。

| 闸 | Q4 被讨厌的勇气 | Q2 心理学与生活 | W13 课题分离 |
|---|---|---|---|
| 必须有一条长片落在主题表 | 三本主题表都没有「弗洛伊德」→ **期望书也全灭** | 早期记忆不在教材主题表 → **期望书灭** | 课题分离不在主题表 → **唯一所在书灭** |
| 仅当别人把该片当主题时才丢「只在正文」的书 | 谁也不把弗洛伊德当主题 → **闲书仍在** | 自卑与超越把早期记忆当主题 → **教材仍灭** | （单书，不触发） |

词法 IR 文献（Tavily，2026-09-16）：BM25F 字段加权（title>body）只改**排序**，不从 5 格里删书。Q4 准是二值，闲书只要还在就 0。SQLite FTS5 已有 `bm25(docs, 3, 3, 1)`，再拧权重救不了准。能当硬过滤的是 **TOC/标题当 aboutness**（章名、书名、地图「能解决什么」是短的主题面；正文里的高 TF 是顺带提及）。

L4：证据片去掉末尾 FUN_CHARS。`梦是` → `梦`。`目的论` 中间的「的」不动。

结构 aboutness（真库 monkeypatch，`.orchestrator/reports/spike7-aboutness-v2.md`）：

- 先剔除死书。
- 证据片限 **2–8 字**（超长黏串不参加，否则「人的一生要经过…」的前缀「人的」会误中）。
- 书名或地图「能解决什么」含该片，或 3–6 字片去掉尾 1–2 字后的前缀（「阿德勒说」→「阿德勒」对上书名）。
- 或：去掉「第 X 章」/开头数字后的**整段章名**是问句的连续子串（章名「梦」对上「梦是怎么被解释的」）。
- **至少一本**有 aboutness 才丢掉没有的；谁都没有则不动（W 短词只在正文）。

结果：Q4 丢掉被讨厌的勇气，留下自卑与超越（章名「梦」）+ 心理学与生活（地图「解释」）；Q1 两本期望都在（书名含「阿德勒」）；Q2/Q5/Q13 不动；W1–W16 所在书都在。

unconstrained 前缀会伤 N15（「人的」），必须有 2–8 字帽。

两路都中的实现漏洞（字面命中抬弱地图）按第 6 轮 Spec 补上：地图侧必须真有长原片才算 both，否则降仅字面。Q13 地图有长片，不受影响。类 2 的「丢掉闲书」靠结构 aboutness，不靠收紧 both。

## 5. 死书 / 导航

死书判定见 §2 类 4，本库只中 `book-f83968a1`。对策：无正文的块按导航件处理（body 空、name 空）；**整本都无正文时 title 也不进字面**（否则书名「徐景贤」仍把它抬进两路都中）。地图仍可索引。不 OCR。

N16 冻结期望是**空**。死书下去后十年非梦（正文里确有徐景贤，命中 13 块）仍会在。成功标准是「死书不占格」，**不承诺 N16 变绿**，也不许为了 N16 把十年非梦藏掉。

导航件：`is_nav_name` 时 `name` 字段改空。N17 在只剥两边之后闸改走「十年一梦」，会变成徐景贤+黄金海；再叠死书闸，徐景贤下。N17 仍可能因「十年一梦」四字落在黄金海正文而有书。成功标准是「导航件块名不得当命中/建议块」，不承诺 N17 变绿。

## 6. 不采用

- 拧 `LIT_GAP`（Q7 与 Q2 不能共用一个常数）
- 把最长档换成「库里存在的最长档」而不改片（Q7 退到毛泽东，闲书仍在）
- 覆盖率/块数闸（Q4 闲书反而是最高）
- 主题词袋 20–40（见 §4）
- 为「大概讲什么」开问句路由（已有 `OVERVIEW_MARKS` 建议块，Q14 空是因为召回就没了；加《》原片即可）
- 内嵌子串退让（N12 负样本）
- 拧 FTS5 列权重当类 2 的完成线（只改排序，准仍 0）
- aboutness 用不限长的片前缀（N15「人的」）

## 7. 建议本轮做的（对类）

1. **有效证据片**：两边剥 DF=0 长片 + 《》整串当原片 + 片尾 FUN_CHARS 剥掉。MATCH / `_match_gate` / 最长片闸共用同一份片。  
2. **both 必须地图真有长片**（补第 6 轮 Spec）。  
3. **结构 aboutness**：结果集里已有一本的书名/地图/章名对上证据片时，丢掉只在正文里沾到的书。  
4. **死书不进字面**。  
5. **导航件块名不进字面**。

合成闸用假专名、假书名，不准出现黄金海/文革史/Q7 原文。

真库完成线（哨兵不是补丁对象）：Q7 路标只有毛选；Q10 没有心理学与生活；Q14 给出被讨厌的勇气导读或地图；Q4 没有被讨厌的勇气；Q1/Q2 两本都在；Q13 仍在；Q6/N12 仍空；W1–W16 所在书仍在；全不得低于 31/32。
