## 1. 本轮要解决什么

上一轮解决了「词在书里却搜不到 / 读不完」。本轮补**编译层**：

1. 生活题（「总怕被讨厌怎么办」）字对不上书里的术语  
2. 「这本书大概讲什么」会不会去通读  
3. 两路结果让 Agent 自己对名单，判断量太大  
4. 重切之后派生说明会过期，没有体检  
5. 线上验收没有逐轮记录和占用/耗时指标  

**产品假设：** 人说了用知识库 MCP，默认答案在书或笔记里。生活题两路都弱时，给「仅地图」的最像项并标明，**不许装没有**；拉丁专名完全不在库（Q6 PyTorch）仍然必须空。

**本轮明确不做：** 向量库当正本、用摘要代替原文、第七个平级工具、隐藏游标、自动把回答写进书、模型改书正文。

## 3. 地图（派生，不是原文）

路径：`资料/书/<slug>/地图.md`。YAML `type: 地图`，`generated: true`。**不是块文件**，`kb_read` 点名 `书/<slug>/地图` 可以读（短），检索的地图通道读它，字面通道**不把地图当正文块**。

书级字段（先做这个；篇级后做）：

```yaml
title: <书名，来自导读>
type: 地图
book: 书/<slug>
generated: true
```

正文固定四段，不许自由发挥成散文：

1. **能解决什么** — 3～8 条，每条 ≤40 字，用提问者的话（处境、怎么办）  
2. **不解决什么** — 1～5 条（防止硬凑）  
3. **建议从哪读** — 身份列表，必须是真实存在的 `书/<slug>/<块>`  
4. **依据块** — 每条「能解决什么」至少挂一个身份  

抬头（导读.md）仍只来自书：书名、书里的一两句、顶层目录。**地图不许写进导读当书名/章名。**

入库未写出合格地图 → 这本**不算成功**（源文件可已归档，但要在回报里标明「缺地图」，并允许补做）。本轮实现可以：工具切完后交 Agent 按模板写地图，再 `verify` 身份存在；或工具调本地流程。**不许**地图身份指向不存在的块。

篇级地图（后做）：每篇 3 句要点 + 3 个能回答的问题。毛选 396 篇，本轮不做完也可以，书级先绿。

## 4. 两路检索

每一次 `kb_search` **两路都跑**，不平均分、不「先语义再字面」当唯一路径。

| 通道 | 打什么 | 作用 |
|---|---|---|
| 字面 | 块正文 + 块名（现有 FTS） | 点名题、术语、篇名 |
| 地图 | `地图.md` 的「能解决什么 / 建议从哪读」 | 生活题、概要题 |

**重合：** 同一身份 `书/<slug>/<块>` 或同一本 `书/<slug>` 两边都出现 → 代码标「两路都中」。Agent 不对两份名单做集合运算。

路标格式（无正文，总共最多 5 条书/笔记；重合优先占名额）：

```text
路标（无正文）
两路都中（优先）：
1. [书] …  身份：…
   建议块：…
   字面：…；地图：…
仅字面：
2. …
仅地图：
3. …
```

空栏省略。仅地图的建议块仍是原文身份，**不是地图全文**。引用必须 `kb_read` 原文（读地图只为概要题 Q14）。

问句偏置（排序用，不删通道）：带书名/篇名/术语 → 字面排前；带怎么办/我总是/处境 → 地图排前。两路都跑。

空结果：拉丁专名两路都无 → 空。中文生活题 → 不得空，至少 1 条仅地图或两路都中，并标明。

## 5. 体检（借卡帕西的 lint，只动派生）

在现有「净化笔记」上加地图扫描（可以仍走 `kb_lint_notes` 的清单协议，或自检附带，**不新开第七扇门**）：

- 地图里的身份在磁盘上还在不在  
- 重切后 `地图.md` 的 mtime/清单是否旧于块文件  
- 笔记 `sources` 是否踩死身份  

只出清单，动手要 Agent 提交。书正文仍不许改。过期地图：重建或标 `stale`。

卡帕西借来的流程对应：

| 他 | 我们 |
|---|---|
| ingest 更新 wiki + index | 入库切块 + 写地图 + 索引失效 |
| query 先 index 再打开页 | 两路路标再读**原文** |
| lint 矛盾/孤儿/过期 | 地图死链 + 笔记净化 |
| 好回答写回 wiki | 只写笔记，且求证 |

## 6. 指标（每次线上验收必记）

写入 `检修/验收记录.md`（只追加，不覆盖）。每题一行或一小节：

| 字段 | 含义 | 窄题/概要题目标 | 宽题目标 |
|---|---|---|---|
| 路标字数 | `kb_search` 返回字符数 | ≤ 1500 | ≤ 2000 |
| 路标含正文 | 埋 token 不得出现 | 0 | 0 |
| search_ms | 热索引后一次检索 | ≤ 2000 | ≤ 2000 |
| 冷启动 ms | 进程内第一次建索引 | 记实数，不挡 | 同上 |
| 读块数 | 实际 `kb_read` 的身份数 | ≤ 2 | ≤ 最少+2 |
| 读总字 | 各窗合计 | ≤ 9000 | ≤ 24000 |
| 轮次 | 检索+随后阅读算 1 轮 | ≤ 2 | ≤ 3 |
| 三栏条数 | 都中 / 仅字面 / 仅地图 | 记实数 | 记实数 |

pytest 管机制（三栏字段在、重合算法、地图身份必须存在、路标无正文）。占用/轮次/生活题是否找对，记进验收记录；Agent 跑线上题后**必须追加一节**，不许改期望来就题。
