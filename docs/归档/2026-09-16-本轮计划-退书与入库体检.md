**Goal：** Agent 能按规则把整本书退出资料室；新进的无文字层进不来；删除后索引立刻失效。

**Architecture：** 不新开工具。`kb_lint_notes` 的 scan 加机械体检，apply 加 `op=withdraw`（仅 `书/<slug>`）。`ingest.convert_one` 在落盘前拦无文字层；空心 slug 走 `book-{hash8}`。抽出 `book_health` / `withdraw_book` 供 lint 和入库共用。

**Tech Stack：** 现有 Python 3.11 + FastMCP + 标准库。零新依赖。
