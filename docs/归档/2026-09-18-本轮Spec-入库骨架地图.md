> 日期：2026-09-18

> **禁止**入库调模型编俗称别名。禁止为单书写特例。

## 要解决什么

Agent 入库才是正路。现在 `convert_one` 只写导读+块，**不写 `地图.md`**（`fill_chapter_names` 没文件就不动）。七本厚地图是实验里手编的，不是工具产的。新书会未入完。

## 改

入库时若没有地图，**机械写一份过 `map_problems` 的骨架**：

- frontmatter：title=导读 title，type 地图，book=`书/<slug>`，generated true
- 能解决什么：3–8 条，从非导航块名截到 ≤40 字（不够 3 条用书名补）
- 不解决什么：固定 1 条「怎么用 PyTorch 训练神经网络」（负样本合同，不是单书规则）
- 建议从哪读：前 3 个非导航块身份
- 依据块：每条能解决什么 → 对应块身份
- 章名：全部非导航块名（可再跑 `fill_chapter_names`）
- 别名：空（校验不强制）

俗称别名、把「能解决什么」改成读者问法：仍 Agent 编，Skill 写明入库后加厚。代码不代写俗称。

## 不改

切块、导读、检索主路径、冻结题集。已有厚地图的书不回写。

## 完成线

pytest 含：入库后有 `地图.md` 且 `map_problems==[]`；旧「缺地图」断言改掉。触及地图生成：真库 Q/W 全组，准/全/省只许升或平（检索未改，期望同分）。
