## 1. 本轮要解决什么

问句原片被套话粘成库里没有的长串，闸门失灵或开在口水词上；书名号被功能字拆碎；扫描死书靠书名占「两路都中」；导航件块名能被搜到；闲书正文里真写了问句那个专名，地图/章名却不是在讲这件事。

**本轮不做：** 向量；新依赖；索引落盘；改书正文；OCR；拧 `LIT_GAP`；主题词袋 20–40；内嵌子串退让；问句类型路由。

## 3. 有效证据片

`evidence_pieces(q) -> list[str]`：

1. `parts = parse_query(q)`。  
2. **《》**：`re.findall(r"《([^》]+)》", q)` 的整串若不在 parts 里就追加。不替代原片。现有 `_quoted_ok` 收窄保留。  
3. **片尾功能字**：片长 ≥2 且末字 ∈ `FUN_CHARS` 则去掉末字，循环直到不是。`目的论` 中间的「的」不动。  
4. **两边剥**：某片 `len≥5` 且 `_df(片)==0` 时，只试去掉前缀/后缀各 1～2 字（保留 ≥3），取全库 DF>0 的最长者。找不到则保持原片。**禁止**在片内部任意切子串。

`query_match`、`_match_gate`、retrieve 的 `_long_pieces` / `_longest_pieces` **都用证据片**，不要有的用 parse、有的用证据。

## 4. 两路都中：地图必须真有长片

`retrieve.py` 现 `bid in lit_set or _map_has_piece` 会把弱地图抬成 both。改成：进 `map_by` 必须 `_map_has_piece(bid, longs)`（`longs` 来自证据片里 len≥3 的最长档）。字面命中但地图没有长片 → 仅字面，再走现成 `_drop_weak_literal`。

**both 仍然不走**「正文拿得出最长片」那一刀（会打掉 Q13：最长片只在地图里）。

## 5. 结构 aboutness（类 2）

在路标名单已经分成 both / 仅字面 / 仅地图、死书已剔除之后、截 5 格之前：

一本有 aboutness，当且仅当下列之一：

- 某条**证据片**满足 `2≤len≤8`，且该片出现在 **书名** 或地图 **「能解决什么」** 正文里；或该片 `3≤len≤6` 时，去掉尾 1～2 字后的前缀（仍 ≥2 字）出现在上述两处。  
- 某非导航块名去掉「第…章」或开头数字后的**整段章名**是问句的连续子串（章名可以 1 字）。  
- 某条证据片 `len≥3` 出现在某非导航块名里。

规则：

- 结果集里**至少一本**有 aboutness → 丢掉没有的。  
- **谁都没有 → 不动**（短词只在正文，W 回捞）。  
- 先死书后 aboutness。  
- 超 8 字的黏串不参加（禁止「人的一生要经过…」用前缀「人的」去撞）。

这是 TOC/书名/地图当 aboutness 的通则，不是主题词袋，不是书名黑名单。

## 6. 死书不进字面

一块：**汉字 <80 且** 图片链接 `![](...)` **≥10** → 无正文块：`body=""`、`name=""`。  
一本所有非导航、非导读、非地图的内容块都无正文 → 死书：这些行的 `title` 也空。地图行照常索引。不 OCR。

检索层兜底：字面通道名单里若一本已是死书，从 both / 仅字面拿掉（仅地图若地图真有长片可留）。

---

## 7. 导航件块名不进字面

`is_nav_name` 时 `name` 字段空字符串（与 body 已空对齐）。`NAV_MARKS` 不改。非导航块不受影响。
