## 2. 实现（retrieve.py，马尾辫 full）

### 2.1 仅字面：最长原片门槛（Spec §3）

现在 `_drop_weak_literal` 里 `_longs_in_corpus` 只留 **DF>0** 的长片，且 `len(longs) >= 2` 才开闸 —— 最长专名整串 DF=0 时闸等于没装。

改成：

1. 取 `parse_query(q)` 里 **len≥3 的原片**（ASCII 数字字母下划线 len≥3 同算）为「长片」。
2. 在这批长片里取**最长的那些**（并列同长全算），**不看 DF**。
3. 一个都没有 → 本条不走（无长片的问句行为不变）。
4. 有 → `lit_only` 里每本必须 `_book_has_piece(bid, p)` 命中其中**至少一片**，否则不占名额。
5. 两路都中（`both`）不动；现有 `LIT_GAP=20` 第二刀保留在所有命中最长片的书之间算，常数**不碰**。
6. 笔记仅字面同样按最长原片过滤；没有长片则不动。

`_longs_in_corpus` 若不再有人用就一并删掉（不预留）。

### 2.2 地图：len<3 残片不许入栏（Spec §4）

`search_maps` 仍宽召回（不改 `index.py`）。在 `retrieve.py` 的 `_format_landmarks` 里：

1. 问句有 len≥3 原片时，地图侧的 `map_by` 条目要**该本地图正文（`能解决什么` + `建议从哪读`）含至少一条这种长原片**才留在 `map_by`；只沾「看」「办」「该」这类 len<3 片 → 不当地图命中。
2. 被踢掉的地图侧：该书若还有字面，就**降成仅字面**，再走 §2.1 的最长原片门槛；地图 why 不再报它。
3. 问句没有任何 len≥3 原片 → 地图侧不动（现有生活题依赖长片，不受影响）。
4. `_why_bits` 地图侧只报 len≥3 的原片；一个字都不许再出现「能解决『看』」。字面侧 `_why_bits` 维持现状（`《实践论》说认识…` 这类靠它出篇名）。
