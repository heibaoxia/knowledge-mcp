## 1. 本轮要解决什么

一类问题：**认字 + 薄提纲 + 闸门** 分不出「这本书在讲这件事」和「正文路过这个词」；说法对不上时闸塌在公共词上。

对类，不对题。对策必须同时解释：

- 说法对不上（问句专名 ≠ 书里专名）
- 二字专名在章名里（「第 X 节」也要认）
- 同名异义（拉丁/中文专名两义）
- 闲书正文真有该词
- 多本都相关时应能一次点齐
- 建议块被公共词挤掉

**本轮不做：** RAG 灌正文；512-token 切块当身份；jieba；问句类型路由；书名黑名单；停用词表（含「变化/发生/分析/关系」）；OCR；改书正文；交叉编码器读正文；HyDE 整句喂 FTS；换六扇门数量；改冻结题集期望（准口径若要改，另开文档等人点头，本轮不改 `docs/验收标准.md` 第九节）；**不在 `mcp/` 里实现客户端「Skill 开门」**（合同见 `需求.md` 与 `docs/Skill-资料室.md`，挂载是 Agent 客户端的事）。

基线（第 9 轮）：准 22/31、全 31/32、省 26/26。Q 组 13/13。W1–W16 全回捞。

## 3. 地图（合格标准加厚）

四段旧模板保留（能解决什么 3–8 条、不解决什么 1–5、建议从哪读、依据块）。**新增两段，代码可机械生成章名：**

```markdown
## 章名
- 第四节 武斗
- 第六卷 第二节 批林整风

## 别名
- 林彪事件 / 九一三 → 书/<slug>/第六卷 第二节 批林整风
```

可选：

```markdown
## 主题词
- 词1
- 词2
```

校验（`map_problems`）：

1. 旧四段规则仍在。
2. **章名段**：非导航、非导读、非地图的块，块名去掉 `第X章`/`第X节`/`第X卷` 前缀后的核心名，至少 **80%** 作为连续子串出现在「章名」段或「能解决什么」里。不足 → 未入完（scan 标，不挡落盘）。
3. **别名**：每条必须 `→` 到存在的 `书/<slug>/…`。左边是专名（长度 ≥2），禁止左边整条等于「变化」「发生」「怎么回事」「一回事」。
4. 主题词若出现：2–40 条，每条 ≤20 字。

`map_index_text` 必须拼进：能解决什么 + 建议从哪读 + **章名 + 别名左串 + 主题词**。

入库：切块成功后，若缺「章名」段，工具用块文件名**机械补上**（不调模型）。别名/能解决什么仍可空着等 Agent；章名覆盖不达标只标未入完。

## 4. 字面：字段 FTS

FTS5 至少这些**可检索列**（UNINDEXED 身份列照旧）：

| 列 | 内容 | `bm25()` 权重（起点，可微调但要进测试） |
|---|---|---|
| title | 书名 | 4.0 |
| name | 块名 | 3.0 |
| aliases | 地图别名左串 + 章名段 + 主题词 | 3.0 |
| body | 块正文（导航件/死书仍空） | 1.0 |

中文仍二字片+单字预切。`NEAR` 本轮可用可不用，不作完成线。

查询侧扩写：**只把别名左串里、与问句有 ≥2 字重叠的专名**并进证据片。禁止把「变化/发生/怎么/什么/一回事」扩进去。扩写词不得出现在路标「命中理由」里（理由只报问句原片或别名左串里问句已有的子串）。

拉丁专名某片全库 DF=0 → 整句空（两路都空）。向量路也必须遵守这条，不得单靠近邻把 Q6/N11 填满。

## 5. 语义：章向量

- **单位**：一个非导航块 = 一个向量。输入 = `书名 + 块名 + 地图里指向该块的别名/能解决什么`（**不要**把整章正文 30 万字送进模型；正文可截前 2k 字，Spec 钉死上限 2000 字）。
- **不是** 512-token RAG 窗，窗仍只给 `kb_read`。
- **模型**：本地；优先已在环境的 onnxruntime 跑中文嵌入。没有权重时，pytest 用**可注入的假嵌入**（确定性哈希向量），不下载模型。真库打分需要真模型：环境变量 `KNOWLEDGE_EMBED=off` 则语义路空、只跑字面（打分记录必须写明）。
- **缓存**：一份 sqlite（FTS + 向量）落在仓库外或 gitignore 路径（建议 `mcp/.kb-index.sqlite`）。入库/退书 `invalidate`。删文件必须能从 `资料/` 重建。
- **不许**：向量分单独决定「有没有」；搜索结果带向量原文或摘录。

## 6. 融合与路标

1. 两路都跑。字面按块召回，语义按块召回。
2. **候选池**按块取 Top `CANDIDATE_LIMIT=30`（RRF，k=60；原查询名单加权 ×2）。再按书收成路标。
3. **输出**仍 `SEARCH_LIMIT=5`。栏名：**两路都中 / 仅字面 / 仅语义**。空栏省略。代码算重合。
4. 多本书都强命中时，5 格允许多本；**不得**为刷准只留一本。
5. 建议块最多 3：先问句里出现的篇名/别名右端身份，再地图依据块，再字面块名命中。`CHAPTER_SUGGEST_LIMIT` 可保持 3。
6. 路标无正文。旧 `SECRET_BODY_TOKEN` 测试必须绿。
7. 生活题两路都弱：给最像的结构命中（地图/别名），标明，不许装没有。

兜底：死书不进字面；导航件 name/body 空。aboutness 认「第 X 节」剥前缀后的章名是问句子串。
