## 1. 本轮要解决什么

一类问题：**检索引擎已经按字段 + 向量搭好，真库地图仍是薄提纲**（七本都是：能解决什么 5–7 条，**章名 0、别名 0**）。说法对不上时，字面没有专名可扩，向量也抬不起该章。

对类，不对题。编地图必须同时服务：

- 说法对不上（问句专名 ≠ 书里章名）
- 二字专名在章名里（「第 X 节」也要列出来）
- 同名异义（拉丁/中文两义靠别名指到对的章，不靠停用词）
- 多本都相关时，地图不要把其中一本写成「不解决」而实际写了同一事

**本轮不做：** 再转 PDF/再入库；改书正文；改冻结题集；为 N7/N8 在 `retrieve.py` 里写专名；改六扇门；Skill 开门；换嵌入模型。

## 3. 谁干什么

1. **代码**（已有，本轮最多补调用）：切块后若有地图缺「章名」，用块文件名机械列出。不调模型。别名、能解决什么 **不准** 工具自动编。
2. **Agent**：读各本块名 + 现有薄地图 + 必要时点名读几章，写出合格 `地图.md`。
3. **代码校验**：`map_problems` / `kb_lint_notes scan`。不合格标未入完，不挡已经落盘的书，不改书。
4. **人**：点头别名方向（尤其史书专名）；不代替 Agent 写检索规则。

不是入库。七本早已在 `资料/书/`。pytest 合成库自己种地图，**本轮真库编地图不算进 pytest**；pytest 只保证校验器仍绿。

## 4. 合格地图（沿用 3.0 Spec §3，真库必须达到）

保留旧四段。新增：

```markdown
## 章名
- <块名，可含第 X 卷/章/节>

## 别名
- <专名> → 书/<slug>/<已存在的章>
```

校验：

1. 旧四段规则仍在。
2. **章名覆盖 ≥80%**：非导航块，剥 `第X章/节/卷` 后的核心名，作为连续子串出现在「章名」段或「能解决什么」。
3. **别名**：每条 `→` 到存在的 `书/<slug>/…`；左边专名长度 ≥2；禁止左边整条等于「变化」「发生」「怎么回事」「一回事」。
4. 主题词若写：2–40 条，每条 ≤20 字。可选，本轮不强制七本都写主题词。

别名写在 **地图文件里**（资料），不是写在 Python 里。地图可以出现书里的历史专名；**代码**仍然禁止用那些真名当规则。

### 证据片通则（12d）

1. **极大原片**：问句原片 A 被另一原片 B 包含，则 A 不拿去扩别名、不当地图命中证据。
2. **别名扩写只认整串包含**：别名左串在原片里，或原片（≥3 字）在别名左串里。禁止「两个更长专名共享一段滑动 N 字」就算命中。
3. **地图命中用原片，不用扩写片。** 有极大原片 len≥3 时，地图正文（能解决什么 / 建议 / 别名左串）必须含其中一片；没有 len≥3 时，必须含问句里 DF 最低的二字片。空证据不得把仅字面抬成两路都中。
4. **仅字面弱命中**：有 len≥3 时仍用最长档；没有时改用「DF 最低的二字片」，闲书只沾高频二字动词的不占格。
5. 合成闸用假 slug / 假专名（核潮 / 奎尔森），禁止真书名和验收题原文。
