## 3. 仅字面：最长原片门槛

问句 `parse_query` 里所有 **len≥3**（或 ASCII len≥3）的原片，取**最长**的那些（并列同长都算）。**DF=0 也当门槛**，不再要求「在库长片 ≥2」。

仅字面的书必须 `_book_has_piece` 命中其中至少一片。命不中 → 不占 5 格。

- **两路都中不动。**
- 问句没有 len≥3 原片：不走本条，只留现成 `LIT_GAP`。
- `LIT_GAP=20` 仍可作第二刀，**不许对着真库改常数**。合成库以「最长原片」为准。
- 笔记仅字面：同样用最长原片；没有长片则不动。

真库对照（哨兵，不是补丁对象）：Q7 闲书没有最长片「讲中国社会各阶级」应下；毛选是都中应留。Q10 心理教材没有「阿德勒心理学里」应下。Q2 仅字面若正文有「早期记忆」应留。

## 4. 地图：单字残片不能入栏

`search_maps` 仍可宽召回。入「仅地图 / 两路都中」的地图侧时：该本地图正文（能解决什么等）必须含至少一条问句 **len≥3** 原片。只靠「看」「办」「来」「该」这种 len<3 → **不当地图命中**。该书若还有字面，降成仅字面，再走第 3 节。

`_why_bits` 地图侧同样只报 len≥3 的原片。不许再出现「能解决『看』」。

生活题：问句里仍有长片（如「不是讨厌我」）写在地图「能解决什么」里的，必须还能仅地图进路标。现有 `test_map_only_life_query` 不得红。
