## 类 A · 源文件没有标题树 / 多册装成一本

**例子：**《资本论》1–3 套装 EPUB。

**现象（人话）：**  
三卷订在一个文件里。里面的 HTML 没有 `# 章名` 这种标题。工具只好看见「第 X 章」就切一刀。「第一册 / 第二册」没当成上级，于是三个「第一篇」撞车，文件夹名叫 `1-3-3`。有的章（原始积累）将近三十万字，要翻三十多个窗。**字本身是通的**，坏的是书架上的分卷、分篇。

**这类还包括：** 任何「一套多册、无 ATX/h1、标题只写在纯文本行里」的书。

**策略（对类，不对这一本）：**

1. **切块前认「册/卷」行当上级**（`第X册` `第X卷` `上册`），再在册内切章；同名章按册加前缀，禁止三个「第一篇」平铺。
2. **slug 保留能读的书名**，不要把中文剥光只剩 `1-3-3`。
3. **入库体检（类闸门，不是单书名单）：** 最大块超过全书一定比例、或一块超过 N 个 8000 窗 → 回报「切点可能丢了层级」，这本书算未入完，留给 Agent 决定要不要重切。不在检索里为资本论开特例。

**第 9 轮已落地（切块 + 退了再入）：** 无 ATX 时认短行「第X卷/册」当上级并加前缀；目录链接不当切点。真库资本论现 `book-6a85baa6`，三册前缀分开。空心 slug 仍走 hash（第 8 轮）。原始积累仍偏长，体检可标超长块。

## 类 B · 转换文本字形坏了、切点过碎

**例子：**《文革史》文字 PDF。

**现象（人话）：**  
多数章节（如红卫兵运动）语义能读。坏在三处：书名变成「第一章 …」；「第一节」「一、」条款被撕成独立文件，有的文件名是乱码；源 PDF 字体把「的」印成「癿」、「不」印成「丌」。同一本里「的」和「癿」并存，**搜「的」对不上「癿」**。这不是扫描件缺字，是字体映射。

**这类还包括：** 有文字层、但标题/条款/字体损坏的 PDF。

**策略（对类，不对这一本）：**

1. **书名：** 有文件名/元数据时不要用第一个「第 X 章」当书名。
2. **切点：** 有 Markdown 标题时不要用「一、」撕篇（需求已写）。无标题的 PDF：条款行（「一、」且后面不是章名）不当成新文件。**第 9 轮已落地。** 文革史 84→67 块，乱码条款文件名不再单列。
3. **字形：** 入库后若某几个非常用字（癿、丌…）出现次数高、且与常用字成对，可做**小映射表**（字体替换，不是改写）。Agent **不重写四十万字正文**——正本仍是转换结果；Agent 只补地图、标「乱码块不必当正文」。
4. **体检：** 文件名含大量非常用汉字、或空壳块（只有标题没有正文）超过一定比例 → 标未入完。

## 类 C · 没有文字层

**例子：** 扫描图 EPUB（无文字层，转出来几乎全是图片链接）。本库那本徐景贤《十年一梦》已于 2026-09-16 退库。

**现象：** 几十兆几乎全是整页图，转出来没有可检索的正文。

**策略：** 图文比过高 → **拒绝算入完**，源文件留在原处或归档时标明「无文字层」。不 OCR（产品已定：只收文字版）。不要为这一本写特例过滤器。

## 类 D · 书多了以后，公共词把仅字面撑满（**已落地第 6 轮**）

**例子：** 问「各阶级的分析」带进文革回忆录；问「商品的价值是怎么来的」资本论排第一，但「价值 / 来」把心理书、回忆录填进 5 格。

**为什么（类原因，不是「黄金海不好」）：**

- 字面通道是语片 OR：问句里有一个很常见的长片（分析、价值、来），库里很多书都会中。
- 路标最多 5 本。库从 4 本涨到 8 本后，弱命中不再被「库太小」挡住。
- 上一轮「仅字面分差 / 最稀长片」是在 **4 本书** 上调的，对「高 DF 公共词 + 新书也真写了这个词」不够。
- 地图「能解决什么」里若留下「来」「怎么办」这种残片，地图通道也会误中。

**策略（对类，不对 Q7）：**

1. **仅字面入路标要有「够稀」的证据：** 只命中问句里 DF 很高的片、又没有章名/书名命中、也没有地图 → 不占 5 格。两路都中、仅地图不动。不要把「分析」「关系」当停用词（需求禁止）。
2. **why / 地图命中只用最长原片**，单字、二字功能残片（来、的）不当地图命中理由。
3. **验收用合成库钉类：** 一本闲书只重复一个高 DF 公共词、期望书有稀词或章名 → 闲书不得进路标。真库打分仍跑全组 Q/W（`docs/验收标准.md` 第九节）；Q7 是哨兵不是补丁对象，不为 Q7 加书名黑名单。
4. 召回允许漏 1 本（验收已写）；红线仍是无关书不得进路标。

**第 6–7 轮已落地：** 闲书弱命中、黏字空壳、死书占字面、导航件空索引。Q 组准 9/13 → **13/13**。N16/N17 随徐景贤《十年一梦》退库已废。

## 现在用起来还哪里别扭（按打分维，不按代码）

数字对照第 7 轮真库。对策仍必须对**这一类问法**生效，禁止为下面某一句写死规则。

### 准 · 路标里掺了不该看的书

问的是 A，单子上却出现 B、C。

- 问「马克思说的原始积累」：资本论对，文革史也挤进来。
- 问「一月风暴」「文革里的破四旧」：十年非梦对，文革史也在；或者两本回忆录/史书缠在一起。
- 问「林彪事件以后局势怎么变化」：五本书一起进路标（毛选、资本论、心理教材、被讨厌的勇气、文革史），像没筛过。
- 问「埃里克森人的一生几个阶段」：心理学教材对，但又带上自卑与超越、资本论（资本论里另有一个叫埃里克森的人）。

### 全 · 该看的书/篇没点名给你

书其实在库里，路标没把你领到该读的那一块。

- 问「武斗是怎么发生的」：该看文革史，给出来的是黄金海回忆录。
- 问「矛盾论、实践论、各阶级分析有什么共同点」：三篇名字在理由里能看到，建议块只点了矛盾论和各阶级分析，**实践论要你自己猜去点**。
- 资本论「原始积累」那一章将近三十万字、三十多个阅读窗：路标能指到这本书，但「从哪一窗读」仍然费。

### 省 · 翻起来费、看起来乱

- 资本论三卷订成一本，文件夹名叫 `1-3-3`，三个「第一篇」平铺。找到了也要连翻很多窗。
- 文革史在路标上显示成「第一章 现代民族国家」，不像书名；有的章文件名是乱码。点开能读，但认路累。
- 「林彪事件以后局势」那类宽问，路标一次塞满五本，占满格子。

### 空 · 库里没有的，不该硬凑一本

- 问「怎么用 Rust 写一个操作系统」：库里没有，却给出《心理学与生活》。
- 「怎么用 PyTorch 训练神经网络」「量子纠缠超光速」这两问现在是空的，是对的，别修坏。
