## 类 A · 源文件没有标题树 / 多册装成一本

**例子：**《资本论》1–3 套装 EPUB。

**现象（人话）：**  
三卷订在一个文件里。里面的 HTML 没有 `# 章名` 这种标题。工具只好看见「第 X 章」就切一刀。「第一册 / 第二册」没当成上级，于是三个「第一篇」撞车，文件夹名叫 `1-3-3`。有的章（原始积累）将近三十万字，要翻三十多个窗。**字本身是通的**，坏的是书架上的分卷、分篇。

**这类还包括：** 任何「一套多册、无 ATX/h1、标题只写在纯文本行里」的书。

**策略（对类，不对这一本）：**

1. **切块前认「册/卷」行当上级**（`第X册` `第X卷` `上册`），再在册内切章；同名章按册加前缀，禁止三个「第一篇」平铺。
2. **slug 保留能读的书名**，不要把中文剥光只剩 `1-3-3`。
3. **入库体检（类闸门，不是单书名单）：** 最大块超过全书一定比例、或一块超过 N 个 8000 窗 → 回报「切点可能丢了层级」，这本书算未入完，留给 Agent 决定要不要重切。不在检索里为资本论开特例。

## 类 B · 转换文本字形坏了、切点过碎

**例子：**《文革史》文字 PDF。

**现象（人话）：**  
多数章节（如红卫兵运动）语义能读。坏在三处：书名变成「第一章 …」；「第一节」「一、」条款被撕成独立文件，有的文件名是乱码；源 PDF 字体把「的」印成「癿」、「不」印成「丌」。同一本里「的」和「癿」并存，**搜「的」对不上「癿」**。这不是扫描件缺字，是字体映射。

**这类还包括：** 有文字层、但标题/条款/字体损坏的 PDF。

**策略（对类，不对这一本）：**

1. **书名：** 有文件名/元数据时不要用第一个「第 X 章」当书名。
2. **切点：** 有 Markdown 标题时不要用「一、」撕篇（需求已写）。无标题的 PDF：条款行（「一、」且后面不是章名）不当成新文件。
3. **字形：** 入库后若某几个非常用字（癿、丌…）出现次数高、且与常用字成对，可做**小映射表**（字体替换，不是改写）。Agent **不重写四十万字正文**——正本仍是转换结果；Agent 只补地图、标「乱码块不必当正文」。
4. **体检：** 文件名含大量非常用汉字、或空壳块（只有标题没有正文）超过一定比例 → 标未入完。

## 类 C · 没有文字层

**例子：** 徐景贤《十年一梦》扫描图 EPUB。

**现象：** 几十兆几乎全是整页图，转出来没有可检索的正文。

**策略：** 图文比过高 → **拒绝算入完**，源文件留在原处或归档时标明「无文字层」。不 OCR（产品已定：只收文字版）。不要为这一本写特例过滤器。

---

## 类 D · 书多了以后，公共词把仅字面撑满

**例子：** 问「各阶级的分析」带进文革回忆录；问「商品的价值是怎么来的」资本论排第一，但「价值 / 来」把心理书、回忆录填进 5 格。

**为什么（类原因，不是「黄金海不好」）：**

- 字面通道是语片 OR：问句里有一个很常见的长片（分析、价值、来），库里很多书都会中。
- 路标最多 5 本。库从 4 本涨到 8 本后，弱命中不再被「库太小」挡住。
- 上一轮「仅字面分差 / 最稀长片」是在 **4 本书** 上调的，对「高 DF 公共词 + 新书也真写了这个词」不够。
- 地图「能解决什么」里若留下「来」「怎么办」这种残片，地图通道也会误中。

**策略（对类，不对 Q7）：**

1. **仅字面入路标要有「够稀」的证据：** 只命中问句里 DF 很高的片、又没有章名/书名命中、也没有地图 → 不占 5 格。两路都中、仅地图不动。不要把「分析」「关系」当停用词（需求禁止）。
2. **why / 地图命中只用最长原片**，单字、二字功能残片（来、的）不当地图命中理由。
3. **验收用合成库钉类：** 一本闲书只重复一个高 DF 公共词、期望书有稀词或章名 → 闲书不得进路标。真库 Q7 只做抽查，不为 Q7 加书名黑名单。
4. 召回允许漏 1 本（验收已写）；红线仍是无关书不得进路标。
