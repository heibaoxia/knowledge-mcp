# 实现计划（一页）

按块做，一块验收过再开下一块。规格以 `需求.md` 为准。

## 技术（已定）

- Python 3.11 + FastMCP + stdio
- 正本是 `资料/` 下的 Markdown；不配数据库
- 转换用 markitdown
- 六扇门对外分开；转换、扫抬头、日志对内共用
- 闸门用 pytest 钉住

## 块

| # | 块 | 做完长什么样 |
|---|---|---|
| 0 | 空 MCP | `mcp/` 能启动；Agent 能看见六扇门（后几扇可回「未实现」） |
| 1 | 入库 | 收件箱入库 + 指定入库，同一条转换。EPUB/PDF → `资料/书/<slug>/导读.md`，源文件进归档 |
| 2 | 检索+阅读 | 检索只回路标；阅读必须点名，有字数顶；书和笔记一起搜 |
| 3 | 写笔记 | 不先搜就拒绝；只能进 `资料/笔记/`；动不了书 |
| 4 | 净化 | 先清单后动手；碰书整单拒绝 |
| 5 | 自检 | 各门写调用/失败日志；查看最近记录；提案进 `检修/提案/`，不改源码 |

## 共用（随第 0～1 块搭起来）

- 路径配置（原始资料 / 归档 / 资料 / 检修）
- 调用日志（给第 5 块用）
- 失败交还格式（卡在哪、为什么、已做成什么、正门还能怎么试）

## 不做（整段计划里都不要做）

向量库当正本、按学科分库、后台定时任务、Agent 直接补丁本工具源码。
