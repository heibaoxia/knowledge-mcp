## 块 6：检索加深一次多块（已完成）

做完长什么样：

- `kb_search` 路标含建议块（书：命中章名，一本一条路标下列最多 2～3 章；笔记：身份）；仍无正文
- 中文问句：整句 + 空白/标点 + 连续汉字二字片，仍只打抬头
- `kb_read` 兼容 `target`+`part`；新接受 `targets: list[str]`（`书/<slug>/<章>`、`笔记/<slug>`）
- 单块 8000 字、最多 5 块、整次 24000 字；超总顶截断并标明剩余项
- 某一块找不到：该块失败交还，其它块照给
- 没身份或清单含整本：整单拒绝
- 不新开工具；不用对象数组

闸门（pytest）：交叉两本一次拿两块；中文无空格问句能同时命中两边抬头；部分失败；整本拒绝；总顶截断；旧单块调用仍绿。

## 块 7：写笔记求证（已完成）

做完长什么样：

- `kb_write_note` 步骤：`preview` → `verify` → `create`/`update`，跳步拒绝
- 同一份稿 = 标题+介绍+正文；`verify`/`sources` 不算改稿
- 求证四选一：`相符` / `部分不符` / `库中无` / `非事实`
- `相符`、`部分不符`：`sources` 身份存在，且调用日志里这些身份已经成功 `kb_read`（窗口：最近 100 条或 24 小时，先到为准）
- `库中无`：来源可空；稿里写「根据《」而无来源则拒绝
- `非事实`：不强制阅读；填了来源则身份必须存在
- 抬头写入 `generated`、`verify`、`sources`
- 工具不联网、不打分、不改书；不新开工具

闸门：不预览/不求证就 create 红；没读过就 `相符` 红；`非事实` 不读可写；读过后 `相符` 绿；想写进书仍红；旧「只 preview 再 create」路径必须变红。
