# Skill：资料室

> 给人点名启用。闸门在 MCP，不在本文。  
> 上级：`需求.md`。第三版检索见 `docs/本轮Spec.md`。

## 何时用

用户说「用资料室」「用知识库」「查库里的书」或点名本 Skill。没点名，不要去调 `kb_*`。

## 开门

这场对话必须已经接上本机 `knowledge` MCP。若工具列表里没有 `kb_search`：告诉用户去启用该 MCP，不要假装查过。

## 用法（短）

1. **先 `kb_search`**，只拿路标（身份、建议块、三栏）。路标里没有正文。
2. **再 `kb_read` 点名** `书/<slug>/<章>` 或 `笔记/<slug>`。一次最多 5 块，单窗 8000，整次 24000。超长用 `章名#2`。
3. 够答就停。不要按目录通读，不要打开 `资料/` 灌全文。
4. 写笔记：`preview` → `verify` → `create`/`update`。声称相符必须先成功读过依据。
5. 退书：`kb_lint_notes` 先 scan，再 apply `withdraw` 点名 `书/<slug>`。不要删文件夹、不要删某一章。

## 不要做

- 把检索结果里的正文摘录进回答（工具也不会给）
- 库里没有却装查过
- 没点名就启用资料室工具
